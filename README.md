# Intercal Labs

Public splash site for **Intercal Labs** — Texas industrial hardware, firmware, software, and field instrumentation.

Canonical domain: [intercallabs.com](https://intercallabs.com)

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

The dev server listens on **port 3847** by default (`http://localhost:3847`).

## Production

```bash
npm run build
npm start
```
